## First Look at Visual Micro

Visual Micro is for people who keep Arduino sketches they own and want one named Visual Studio desk, not mixed board copies. It gives you an Arduino desk, own sketches, and a short path back to a board you already run. It does not replace Visual Studio. It sits beside Visual Studio and keeps the sketches close.

Work stays on sketches and boards you own. Extra boards wait for their own title.
